    02 / EVENT GRAPH

    입력 이벤트와 연결

    버튼을 누르면 이 프레임의 원본 데이터를 CPU로 읽습니다. 모델 추론이나 GPU 작업은 시작하지 않습니다.

    + 극성− 극성정확한 이웃
    x · y · t / 3D

    3D 드래그: 회전 · XY/XT 드래그: 이동 · 휠: 확대 · 노드 클릭: 전체 이웃 조회. 키보드 방향키와 + / −, 0으로도 시점을 조절할 수 있습니다.

    노드를 선택하면 표시용 엣지 부분집합과 별도로, 해당 노드의 정확한 전체 이웃을 강조합니다.
